# Verification and release evidence

This directory holds dated records, not architecture requirements or source code.

- [`phases/`](phases/) contains phase implementation, review, and release-readiness records.
- [`audits/`](audits/) contains runtime and cross-phase investigations.
- [`artifacts/`](artifacts/) preserves raw JSON reports, screenshots, and supporting files from earlier phases.
- [`restore-drills/`](restore-drills/) and the JSON receipts at this directory's top level record local Phase 11 operational checks.

Start with the [current plan](../../tasks/plan.md) and [task ledger](../../tasks/todo.md) for what is authorized or still gated. A passing local test record does not imply independent publication, hosted deployment, or a populated persistent catalog. For system rules, use the [architecture index](../architecture/README.md); for code ownership, use the [codebase map](../development/codebase-map.md).
